# Career Space

Career Space is a Bengaluru education company working at the intersection of
mathematics education, career guidance and teacher training — helping students
discover paths they didn't know they'd love, and giving educators the tools to
make that discovery possible.

This is the website and content studio: a public site for the brand and a
password-protected `/admin` area for managing blog posts, newsletter
subscribers and campaigns.

## Development

Prefer working locally? You need Node.js and npm.

```sh
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
